# NXLoad

Відкрий картку гри кнопкою **A**. **L/R** перемикають огляд, скриншоти та файли. У галереї гортай стрілками **←/→**.

Назва, опис, видавець і дата виходу беруться з індексу [TitleDB](https://github.com/blawar/titledb), вбудованого в `NXLoad.nro`. Ручні українські описи з `tools/descriptions.uk.json` мають пріоритет. Решта українських описів береться з пакетного перекладу в `tools/translations.uk.json.gz`. Якщо український опис відсутній або машинний переклад має ознаки пошкодженого тексту, використовується оригінал TitleDB. **X** у вкладці «Огляд» перемикає між українським описом та англійським оригіналом, коли доступні обидва. Галереї 1-2-Switch і MySims Cozy Bundle з [Nintendo Life](https://www.nintendolife.com/games) також вбудовані у збірку. Для решти ігор NXLoad завантажує галереї Nintendo Life, а за недоступності сторінки показує знімки Nintendo, якщо їхні посилання є в TitleDB. Обкладинка та перелік файлів надходять із вибраного каталогу. За наявності знімків на картці ROMsHQ вони доступні в галереї.

Файли від 32 МіБ NXLoad завантажує у 4 з’єднання, а від 512 МіБ у 8. Сервер DLArchive має підтримувати HTTP Range і надавати сильний ETag. Окремий потік записує отримані блоки на microSD, поки триває передача. Якщо сервер ігнорує запити по частинах, NXLoad використовує один потік.

Нативний каталог Nintendo Switch та завантажувач DLArchive для microSD.

Скопіюй `NXLoad.nro` у `switch/` і запусти через Homebrew Menu.

- **A** відкриває картку гри. На вкладці «Файли» вона завантажує вибрану базову гру, оновлення або DLC.
- **L / R** гортають каталог. **X** шукає по локальному індексу. **ZR** оновлює повний каталог.
- **Y** перемикає екран завантажень. На ньому видно прогрес і вже збережені файли. **X** скасовує активне завантаження.
- **A** на екрані збережених файлів відкриває DBI, якщо він є на карті. У DBI вибери файл у `switch/SwitchDownloadProbe/` через Browse SD Card.
- **B** повертає назад. **+** виходить.

NXLoad читає каталог з NSRoms і отримує актуальне посилання від API DLArchive перед кожним завантаженням. Готові файли зберігаються в `switch/SwitchDownloadProbe/`, тож файли попередньої тестової версії доступні в NXLoad.

## Збірка

Потрібні Python 3, devkitA64, libnx, switch-tools, switch-pkg-config, switch-sdl2, switch-sdl2_ttf, switch-sdl2_image, switch-libxml2, switch-libarchive і switch-zlib. Запусти `bash tools/build-network.sh`, потім `make`. Під час першої збірки Make формує індекс ROMFS із зафіксованого знімка TitleDB та завантажує знімки двох вбудованих галерей Nintendo Life. GitHub Actions зберігає готовий `NXLoad.nro` в артефакті `NXLoad`.

NXLoad перевіряє HTTPS через Mbed TLS з вбудованим набором публічних кореневих сертифікатів [Mozilla CA](https://curl.se/docs/caextract.html), ліцензія MPL 2.0.

Повний каталог NSRoms завантажується у фоні при першому запуску та зберігається в `switch/NXLoad/catalog.bin`. Під час наступних запусків кеш читається одразу, а фонове оновлення запускається, якщо минула доба. Завантаження файлів призупиняє індексацію між запитами.

### Оновлення українських описів

Запусти **Translate NXLoad descriptions** у GitHub Actions після оновлення знімка в `tools/title_db.py`. Завдання розподіляє описи між паралельними виконавцями, перекладає їх моделлю Argos English → Ukrainian, зберігає результат у гілці запуску та збирає `NXLoad.nro`. Порівняння вихідного тексту за SHA-256 дає змогу пропускати записи, які вже перекладені й не змінилися. Щоб відредагувати конкретний опис, додай його до `tools/descriptions.uk.json` за Title ID гри.

### ROMsHQ та RAR

- Бібліотека об’єднує NSRoms і ROMsHQ. Якщо гра однозначно збігається за назвою, її джерела відкриваються з однієї картки. У вкладці «Файли» спочатку відкривається вибір між **NSRoms** та **ROMsHQ**. Стрілками обирається джерело, а **A** завантажує список файлів лише вибраного джерела. **B** повертає до двох джерел. Якщо джерело не містить цієї гри або його каталог не завантажився, воно відображається як недоступне. **ZR** у бібліотеці оновлює каталоги, а помилка будь-якого джерела показується окремо. Для ROMsHQ відбираються картки з позначкою Switch або Nintendo Switch. Перелік файлів використовує ID кнопок Base Game, Update, DLC і дзеркал, які підтримує завантажувач.
- NXLoad робить запит підпису ROMsHQ при виборі файлу. Якщо сайт вимагає перевірку браузера, на екрані «Завантаження» можна натиснути **ZR** і вставити кінцеве посилання ROMsHQ `/d/` або DataNodes.
- Після завантаження RAR пакети NSP/XCI/NSZ/XCZ розпаковуються на microSD. Архів залишається в папці `switch/SwitchDownloadProbe/`. Щоб розпакувати наявний архів, скопіюй його у цю папку, виділи в «Завантаженнях» і натисни **A**. Пакети з’являються у списку після завершення перевірки і запису. Архіви з паролем і набори з кількох томів наразі потребують окремої обробки.
