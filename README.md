# Switch Download Probe

Нативний `.nro` для Nintendo Switch. Збірка 0.4 працює через інтернет з консолі і пише файл напряму на microSD.

## Запуск

1. Скопіюй `Switch-Download-Probe.nro` до папки `switch/` на microSD.
2. Запусти програму в Homebrew Menu.
3. Натисни **X**, щоб спробувати підхопити 1Fichier-дзеркало базової гри **A Pretty Odd Bunny** зі сторінки NSWGF.
4. Якщо NSWGF недоступний або дзеркало відсутнє, натисни **Y** і введи посилання 1Fichier або код файлу після `?`. **B** скасовує передачу, **+** закриває застосунок.

**A** повторює діагностику Buzzheavier для попереднього прикладу, My Cozy Room.
1Fichier працює штатними гостьовими HTTP-запитами. Екран показує очікування, отримані байти й HTTP-код. Якщо сервіс повертає браузерну перевірку або невідому форму, завдання зупиняється з поясненням.
Файл пишеться до `switch/SwitchDownloadProbe/`. Розширення `.part` знімається після успішного завершення передачі. Докачування в цій тестовій збірці відсутнє.

## Збірка

У devkitPro потрібні devkitA64, libnx, switch-tools, switch-curl, switch-zlib і switch-libxml2. Запусти `make`. GitHub Actions зберігає готовий NRO як артефакт.
